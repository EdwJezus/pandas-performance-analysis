## 📊 Análise de Desempenho Escolar
Análise exploratória de dados sobre o desempenho de alunos
em uma turma fictícia, com foco em identificar padrões entre 
frequência, notas e resultado final.

## 🎯 Objetivos
- Praticar manipulação de dados com Pandas
- Explorar correlações entre variáveis
- Gerar visualizações informativas

## Tecnologias
- Python 3.11
- Pandas, Matplotlib, Seaborn
- Jupyter Notebook
  
## 📂 Estrutura
| Pasta | Conteúdo |
|-------|----------|
| data/ | Dataset CSV com dados dos alunos |
| notebooks/ | Notebook com a análise completa |

## ▶️ Como executar
```bash
pip install -r requirements.txt
jupyter notebook notebooks/analise alunos.ipynb 
Principais Insights
1.Frequência é o maior preditor de aprovação
2. Mediana superior à média indica assimetria negativa
3. Alunos com mais de 8 faltas concentram 100% das reprovações
```
